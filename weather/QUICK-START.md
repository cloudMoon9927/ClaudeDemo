# 🚀 天气应用快速启动指南

本指南将帮助你在5分钟内启动并运行天气应用。

## 📋 前提条件

- Node.js 14.0.0 或更高版本
- 现代浏览器（Chrome、Firefox、Safari、Edge）
- 网络连接（用于加载CDN资源）

## ⚡ 快速启动步骤

### 步骤 1：安装依赖 (30秒)

```bash
# 进入项目目录
cd weather

# 安装依赖包
npm install
```

### 步骤 2：启动服务器 (10秒)

```bash
# 启动开发服务器
npm run dev
```

你应该看到：
```
天气应用服务器正在运行...
服务器地址: http://localhost:3000
健康检查: http://localhost:3000/api/health
```

### 步骤 3：访问应用 (5秒)

打开浏览器访问以下任意地址：

- 🌤️ **天气应用主界面**: http://localhost:3000
- 🧪 **应用测试工具**: http://localhost:3000/test-app.html
- 📋 **项目状态检查**: http://localhost:3000/test-setup.html

## 🎯 功能体验

### 无需API密钥即可体验的功能

✅ **所有基础功能都可以直接使用！**

1. **自动定位** - 允许浏览器获取你的位置
2. **城市管理** - 搜索和添加城市（使用演示数据）
3. **实时天气** - 查看当前天气信息
4. **天气预报** - 查看7天预报
5. **逐小时预报** - 查看24小时趋势图
6. **主题切换** - 暗色/亮色主题
7. **响应式设计** - 在不同设备上测试

### 需要API密钥的功能

⚠️ **以下功能需要配置OpenWeatherMap API密钥**

- 真实的天气数据（非演示数据）
- 全球城市搜索
- 准确的地理位置服务

## 🔧 配置API密钥（可选）

如果你想要真实的天气数据：

1. 访问 [OpenWeatherMap](https://openweathermap.org/api) 获取免费API密钥
2. 复制 `.env.example` 为 `.env`
3. 编辑 `.env` 文件，填入你的API密钥
4. 重启服务器：`npm run dev`

详细配置请参考 [API配置指南](API-SETUP.md)

## 🐛 常见问题

### Q: 应用显示"演示模式"是什么意思？
A: 这表示应用正在使用内置的演示数据，而不是实时天气API。所有功能都可用，但数据是模拟的。

### Q: 如何获取真实的天气数据？
A: 需要注册OpenWeatherMap账户获取API密钥，详见API配置指南。

### Q: 应用支持哪些浏览器？
A: 支持所有现代浏览器，包括Chrome 60+、Firefox 55+、Safari 12+、Edge 79+。

### Q: 为什么位置获取失败？
A: 请确保浏览器允许位置访问权限，或者手动添加城市查看天气。

## 📱 移动设备测试

### 手机测试
1. 确保手机和电脑在同一网络

3. 测试触摸操作和响应式布局

### 平板测试
1. 测试横屏和竖屏模式
2. 验证侧边栏在不同方向下的表现

## 🎨 自定义主题

### 修改颜色主题
编辑 `public/css/style.css` 文件：

```css
/* 修改主色调 */
body {
    background: linear-gradient(135deg, #你的颜色, #你的颜色);
}

/* 修改暗色主题 */
body.dark-theme {
    background: linear-gradient(135deg, #你的暗色, #你的暗色);
}
```
