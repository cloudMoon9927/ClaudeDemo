## 💾 项目配置摘要

### 环境要求
- Node.js 14.0.0+
- 现代浏览器（Chrome/Firefox/Safari/Edge）
- 网络连接（CDN资源或本地部署）

### 启动命令
```bash
cd weather
npm install    # 首次运行
npm run dev    # 开发模式（热重载）
npm start      # 生产模式
```

### 访问地址
- 主应用: http://localhost:3000
- 功能测试: http://localhost:3000/test-features.html
- 健康检查: http://localhost:3000/api/health
